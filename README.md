# Coordinate Range Mapper

**Free online coordinate plotting and conversion tools.** No registration, no API key.

🔗 **[map.basesite.org](https://map.basesite.org/)**

## Tools

| Tool | Description |
|------|-------------|
| [Mapper](https://map.basesite.org/mapper) | Plot DMS & decimal coordinates on an interactive map. Batch input, polygon closure, area/perimeter calculation, GeoJSON export. |
| [Converter](https://map.basesite.org/converter) | Convert coordinates between DMS, Decimal, and DMM formats instantly. Auto-detects input format. |
| [Guide](https://map.basesite.org/guide) | Step-by-step tutorial and FAQ. |

## Features

- **Dark & Light themes** — toggle with one click
- **English / 中文** — language switch
- **Geolocation** — auto-detect your position
- **GeoJSON export** — compatible with QGIS, Google Earth
- **Batch input** — paste dozens of coordinates at once

## Tech Stack

- [Leaflet](https://leafletjs.com/) + [OpenStreetMap](https://www.openstreetmap.org/)
- Vanilla HTML/CSS/JS — zero build step
- Deployed on [Cloudflare Pages](https://pages.cloudflare.com/)

## Local Development

Open `index.html` in a browser. That's it.
